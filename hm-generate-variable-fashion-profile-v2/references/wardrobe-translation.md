# 服装转译指南

仅在服装叠穿、图案复杂、部分遮挡或服装类别不容易判断时读取本参考。

## 覆盖检查

确认参考图能看见：

- 最外层和可见的内搭；
- 上装、下装的长度与体积；
- 袖型和裤/裙形状；
- 鞋子、袜子或露出的脚踝；
- 明显影响人物轮廓的配饰。

如果关键区域被遮挡，要求补充照片或简短文字说明。只有头像照片不能证明完整穿搭。

## 服装映射

| 照片中的服装特征 | 涂鸦式转译 |
| --- | --- |
| 修身西装或套装 | 保留肩线、翻领、门襟和衣摆；用几个几何色块与断续线代替剪裁细节。 |
| 大衣或风衣 | 保留长度、领型、腰带/口袋节奏以及宽松或合体的体积；省略精确缝线结构。 |
| 连帽衫或卫衣 | 保留帽子体块、领口、袖口、袋鼠袋和宽松体积；使用大面积柔和色块与少量褶皱线。 |
| 衬衫或女式上衣 | 保留领子、门襟节奏、袖子体积和收束/衣摆；纽扣简化为少量不规则点。 |
| T 恤或球衣 | 保留领口、袖长、衣身合体度和主要分区颜色；文字、徽章、赞助商标志抽象化，除非用户明确要求。 |
| 针织服装 | 用少量断裂排线表现织物暗示，不做密集的真实纤维模拟。 |
| 连衣裙或半裙 | 保留腰线位置、衣摆长度、展开度、开衩和运动方向；用一两个主体色块加松散褶皱线表现。 |
| 牛仔裤或长裤 | 保留裤腰高度、裤腿宽度、长短、卷边和主要口袋；用几何色块表达褶皱。 |
| 运动服 | 保留明显的拼接几何、色块、条纹节奏和廓形；简化品牌与技术面料细节。 |
| 图案面料 | 保留图案家族和大致尺度，再用弯曲、断裂、重叠、错位的手绘线重新画出。 |
| 鞋子 | 保留鞋类和鞋底/侧面的轮廓；简化为不规则外轮廓、两三个面片和少量鞋带。 |
| 包或首饰 | 只保留影响轮廓的物件；小细节化为几笔符号或省略。 |

## 遮挡规则

- 只能根据可见边缘、对称关系或重复图案，推断一小段直接被遮挡的延续。
- 不要推断不可见的其他服装类别、颜色、鞋型或配饰。
- 手臂遮住西装前襟时，保留能看到的翻领、衣摆和体积，不要发明完整门襟细节。
- 长外套遮住裤子时，只重现可见的裤腿部分，并让外套保持主体地位。

## 服装清单示例

### 休闲叠穿

`炭灰色宽松连帽衫，外搭短款橄榄绿工装夹克；宽松黑色直筒裤；米白色厚底运动鞋；小型斜挎包；深色中性色为主，带一个橙色强调色。`

### 正式套装

`单排扣海军蓝西装，宽翻领、放松肩型；白色敞领衬衫；全长宽腿裤；黑色低调皮鞋；以海军蓝和米白色为主，加入少量灰褐色几何阴影。`

### 运动套装

`红色短袖足球上衣，深海军蓝胸部横带与白色分隔线；搭配指定的短裤或长裤、运动袜和运动鞋；保留拼接节奏，同时将文字、徽章和赞助商标志抽象化。`
