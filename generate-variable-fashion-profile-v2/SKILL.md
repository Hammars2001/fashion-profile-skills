# 百变服装侧脸时装涂鸦 V2

生成一张竖版、全身、行走中的时装人物插画。使用
`assets/style-master-reference.png`——用户最终选定的“图二”——作为笔触、色块、抽象程度、步态节奏、方格纸版式和编辑感的最高优先级参考。上传照片只负责提供人物身份与可见穿搭。

## 版本定位（必须遵守）

- **V1：固定穿衣风格。** V1 的衣服、配色、鞋袜和整体穿搭是模板的一部分，只替换头像、发型、脸型以及可选的身高比例。
- **V2：百变穿衣风格。** V2 固定的是图二的画风、线条语言、平面化处理、步态节奏、构图和背景版式；衣服必须根据本次上传照片中实际可见的服装自由变化。
- V2 的女性银灰套装照片与插画只是第二个工作范例，不是女性服装模板，也不限制性别、服装类别、颜色或配饰。
- V2 的第一个范例是从 V1 原样平移过来的身高案例，用来承接已有标准；它不应把 V2 重新变成固定穿搭技能。
- 保留 `assets/style-source-reference.png` 仅作为风格来源记录；正常生成时不要把它作为主要参考图。以 `assets/style-master-reference.png` 的图二效果为准。

## 输入约定

- 要求提供清晰的侧脸人物参考图；优先使用左侧脸。若只有清楚的右侧脸，可在不改变身份特征的前提下水平翻转。
- 要求参考图能看见希望在全身插画中呈现的服装。人物身份和穿搭可以来自同一张照片。
- 如果衣服、裤裙或鞋子被遮挡，要求补充照片或简短文字说明；不要默认凭空发明不可见的服装。
- 身高可选，未提供时使用 `170 cm` 作为基准。
- 忽略照片中的场景、灯光、材质纹理、镜头畸变、车辆、路人、文字和无关道具，除非用户明确要求保留。

## 参考图优先级

出现冲突时按以下顺序处理：

1. 用户的明确指令。
2. 上传照片中的人物身份，尤其是颈部以上的头型、发型、脸型、侧脸轮廓和神态。
3. 上传照片中的可见服装、鞋子和影响轮廓的配饰。
4. `assets/style-master-reference.png` 提供画风、步态、构图、背景和抽象程度。

主风格参考图不控制 V2 的衣服。不要把它的米灰风衣、红围巾、蓝色墨镜、红色线格纹长裤、橙色袜子或米色鞋子带入新图，除非本次服装照片确实显示这些元素。

## 图二的视觉语言

遵循图二中各元素之间的关系，不要用泛化的“粗糙艺术风”重新解释原始参考图。目标是松弛、手绘、略带失真、可读但不写实的时装速写。

### 线条

- 让线条承担约 60% 的结构，色块承担约 40% 的体积。
- 以细而不均匀的黑色墨线为主，压力和速度有变化。长轮廓要读得出来，但允许轻微游移、折弯、重描、交叉、越界和没有完全闭合。
- 身体轮廓使用相对果断的线；头发、脸、眼镜、手、口袋、衣摆和鞋带使用紧张的寻找线、回环线和短促涂写。
- 允许局部断线和不闭合，但不能让人物大面积消失。抽象感来自位置的不精确、局部错位和选择性细节，而不是把画面做成残缺轮廓。
- 手、鞋、五官、缝线和褶皱用经济的速写符号表示，避免精细解剖或产品结构绘制。

### 色块

- 使用平涂、哑光、基本不透明的数字色块，边界不规则但表面相对平整。不要模拟干刷、蜡笔、水彩颗粒、撕纸边或厚重颗粒噪点。
- 允许色块略微越过轮廓、提前停下、互相重叠或悬浮在线条旁边，形成轻微错位感。
- 用少量大而有棱角的非写实阴影表现体积；阴影可以是橄榄棕、灰褐、暖灰或深海军蓝，不必服从真实光源。
- 衣服底色保持大面积、安静、平面化；只有在服装照片支持时，才加入一到两个高饱和强调色。
- 在部分色块之间保留纸张空隙，但要让人物和衣服整体仍然清楚、完整、可辨认。

### 图案与涂鸦元素

- 将格纹、条纹、拼接、针织、徽章或运动图形转译成手绘线叠加或简化几何符号。
- 重复线条要顺着衣服弯曲，并允许撞线、漏交点、间距变化、越过衣摆和局部未完成。
- 高密度涂写只能作为局部重点，例如头发、图案服装、鞋带或一个焦点配饰，不要覆盖所有表面。

### 面部与身份

- 通过头部/帽子/头发外轮廓、眉到鼻梁的侧面关系、嘴、下巴、耳朵、面部毛发位置和神态角度保持相似度。
- 皮肤使用几个温暖的平面色块，再加两到三个深色几何面；不要画毛孔、渐变或真实面部光影。
- 有须根时使用稀疏、断续的灰黑色短线；不要把须根画成整齐的深色实心胡子。

### 背景与构图

- 使用温暖的米白色纸张底色，四周保留较多留白。
- 人物身后放置一个矩形方格纸区域：细淡灰色小格，叠加更醒目的钴蓝色主网格线；整体规则可辨，但允许轻微手绘不完美。
- 保持竖构图、全身、左侧脸行走姿态：身体略向前倾，肩膀放松，一只脚着地，一只脚抬起，双鞋都要完整出现。

## 服装转译

生成前先提取简短的服装清单：

- 服装类别与层次顺序；
- 廓形、宽松程度、长度和体积；
- 领口/帽子/翻领、袖型、腰部、衣摆和裤裙形状；
- 鞋子、袜子和影响轮廓的可见配饰；
- 主色、强调色和图案节奏。

保留类别、廓形、层次、长度和颜色识别度；将真实褶皱替换为少数黑色手势线和几何平涂阴影，删除细小缝线与五金细节。除非用户明确要求，否则把难以辨认的文字和精确 logo 简化为抽象标记或省略。

对于叠穿、复杂图案、局部遮挡或运动服，读取
[references/wardrobe-translation.md](references/wardrobe-translation.md)。

## 身高变量

- 以 `170 cm` 为基准，使用以下风格化比例：

  `leg_scale = clamp(1 + (height_cm - 170) / 100, 0.80, 1.30)`

- 参考值：`160 → 0.90`、`170 → 1.00`、`180 → 1.10`、`190 → 1.20`。
- 这是插画中的比例控制，不是人体测量结果。
- 沿行走方向调整大腿和小腿长度；保留头部大小、躯干、肩宽、髋部锚点、膝盖弯曲、脚尖方向和鞋子大小。
- 同步延长或收缩与腿相连的裤裙部分，并保持图案的视觉密度；只做最小限度的重新构图，确保双鞋完整可见。不要整体放大人物来表示身高。

**提示词建议：**只要输入对应人物的身高即可定义大概的腿长比例。Skill 会以 `170 cm` 为基准自动估算腿部长度，不需要用户手动填写百分比。

## 工作流程

1. 用图像查看工具检查上传图片与 `assets/style-master-reference.png`。除非用户询问风格来源，不要加载 `assets/style-source-reference.png`。
2. 明确分配角色：主风格/步态参考、人物身份参考、服装参考和可选细节参考。
3. 检查服装是否覆盖完整；无法支持全身穿搭时先请求补充信息。
4. 写出服装清单并计算 `leg_scale`。
5. 使用内置图像工具生成：主参考图控制风格，但必须明确禁止其服装向新图迁移。
6. 生成一张竖版、单人物、无摄影场景的插画；除非用户要求，不加入文字、logo、道具或其他人物。
7. 对照主参考图检查线条与色块比例、细而游移的线条、平涂色块、几何阴影、局部涂鸦、方格背景、人物身份、服装和身高比例。
8. 如果明显偏离图二、变成写实摄影、出现材质纹理、过度空缺或画风泛化，最多重试一次，只修正观察到的偏差。不要默认把画面做得比图二更抽象。
9. 非破坏性保存并展示结果。

## 偏差修正

- 如果像写实的时装素描：压平渐变，把褶皱替换为两三个几何色块，减少解剖细节，并让线条与色块略微独立。
- 如果像粗糙的粉彩拼贴：去掉颗粒和刷痕，恢复平整的平涂色块与细黑墨线。
- 如果画面过空：恢复可读的人体和衣服轮廓，只保留局部断线，不要制造大面积空洞。
- 如果线条太干净：增加重描、越界、折弯、回环和不完美连接，但保持线宽整体偏细。
- 如果色块太规整：移动和重塑边界，使它们轻微错过或穿过轮廓，同时保持人物可读。
- 如果服装变得泛化：强化领口/帽子/翻领、衣长、体积、衣摆、裤腿宽度、鞋型、层次和关键色彩位置。
- 如果 V1 的衣服泄漏到新图：再次强调主参考图只控制风格和步态；必须替换为本次服装参考中的所有可穿戴物。
- 如果人物身份变弱：只加强侧脸轮廓、头发/帽子体块、鼻子、嘴、下颌、下巴、耳朵、神态和须根位置。
- 如果照片场景出现：恢复米白纸张底和矩形蓝灰方格纸区域。
